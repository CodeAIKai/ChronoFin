# 研究定位与贡献

ChronoFin「时证」研究金融简报的生成与核查：结论既要有证据支持，也要表达重要反证、期间口径和信息未知边界。现有金融问答、报告生成、claim级评价与多维rubric为本项目提供方法基础，具体工作及版本见[调研与方案选择](调研与方案选择.md)。

## 已实现的设计

| 设计 | 实现与作用 | 证据与边界 |
| --- | --- | --- |
| 反证修订流程 | 保留Hy3初稿，结合公开资料、本地计算反馈及反证检查生成修订稿 | 同调用次数对照中，后续15题诊断均分高5.339，平均全流程tokens少30.6%；样本较小且作者可见 |
| 来源与候选双端片段绑定 | 模型选择原文行号和候选句ID，程序精确截取文字并检查身份 | 降低伪造引文风险；片段存在不等于语义支持 |
| 类型化财务运算 | 限定比例、增长、差额和单位转换，由程序编译执行并反馈 | 原生PDF最终12题完成；AP02重复跨期输入仍产生无效计算，说明算术正确不等于财务正确 |
| 评估器验证 | 将破坏性、等价性、顺序、重复与金额语义对照纳入评测 | 同时报告判别力与误报；最终原生PDF的9个有害变形均降分，9个重复/等价处理中仍有1个变化超过5分 |
| 可追溯结果 | 冻结资料、提示与关键代码，保存原回答、修订、评判和历史失败 | 离线复算检验实现一致性；不能替代独立专家正确性判断 |

## 与已有工作的关系

本项目的贡献是针对金融证据核查的组合实现和实证验证。多维金融评价、claim拆解、反证审阅及工具计算均有既有研究，项目未运行外部框架的统一榜单对照。

实验分别测量应用改进与评估器表现。同调用次数比较控制了修订调用数量；固定裁判复評控制了评判版本变化；公开人工标签验证测量正确、错误与拒答的三分类一致性。各对照的完整原始结果与负结果见[实验分析报告](最终实验分析报告.md)。

主要外部效度限制为作者可见的小样本、同模型家族偏差、共享问题的新响应验证，以及尚无新增十维专家盲标或真实研究员试用。
