# 官方要求与原项目审计

本文件属于 ChronoFin「时证」犀牛鸟个人活动作品。审计日期：2026-09-09 UTC。

## 官方依据

依据《犀牛鸟开源-实战任务-混元大语言模型项目.pdf》，共四页。全文提取记录为 `audit/official_task_full_text.txt`。第 1–2 页对应本项目选择的任务 1；第 3–4 页属于另一项过程评估任务，没有把后者的强制指标冒充任务 1 要求。

官方要求自行创建公开仓库并提交链接，不要求向 Hy3 官方仓库提 PR；README 介绍项目、运行方式和环境；API Key 由环境变量或配置传入；项目命名与 README 标明个人/活动作品；模型调用通过 Hy3，无需训练或微调。

任务 1 要求输出不存在唯一标准答案的真实应用，解释目标用户、问题与模型必要性；建议五个以上可操作维度；样本包括难例和反例；必须完成判别力及一致性验证，对抗性验证为鼓励项；交付源码、评测材料、完整结果与分析报告、两分钟以内视频或 GIF。本项目实现十维判据，并完成对抗验证。

本项目的十维权重、门禁与0–100分用于实验诊断，由项目自行定义；任务PDF未将这些数值规定为官方评分。

## 优势与限制

| 原项目证据 | 实际优势 | 严格评审中的限制 |
|---|---|---|
| 时间过滤与注册表回绑 | 来源时间不由模型决定，可拦截明确未来资料 | 文档发布日期依赖清单，不能自动还原首次公开时间、时区或重述版本 |
| 安全公式解释器与类型化结论 | 算术可执行，可追踪证据依赖 | 数值框架不等于开放式分析质量；语义口径仍需要判断 |
| 121 项测试与受控变形 | 工程投入扎实，回归覆盖较好 | 模板生成的 2736 项不能算 2736 个独立真实研究任务 |
| 历史真实 PDF 回答与挑战集 | 已考虑真实材料和失败迭代 | 真实主披露链较少，已见数据回归不能称独立盲测 |
| 事实文字和摘要确定性投影 | 降低未经核验散文进入最终报告的风险 | 投影会替换模型原话，掩盖原始生成错误，也让分析接近引句集合 |
| 十维评分 | 比单一“看起来不错”更可操作 | 词法支持不能代替蕴含；作者模板、错误注入器与评估器共享假设可能使高分过于容易 |

原项目的时间过滤、引用回绑、计算与回归测试为新增实现提供基础。新增开放式研究流程扩大资料覆盖，保留原始回答与修订，验证重要反证遗漏，并测量语义裁判的顺序波动。
