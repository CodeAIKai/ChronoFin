# 数据、来源与复现说明

## 三层真实资料与评测单位

资料卡集 `data/brief/` 包括Meta FY2024、Amazon FY2024、TSMC Q4 2024、IEA《Energy and AI》、美联储2025年4月金融稳定报告五项一手来源。39张卡片是作者核对的事实/英文转述，不是PDF逐字引文；均有实体、位置、公开日、数值与单位。20题分5个开发题和15个后续题，作者见过所有题，不是人员盲法。19题按口径/期间/反证/未知/时点标为难例，尚无专家难度标定；含2个整体不可答和2个部分可知例，类别可交叉。

美联储资料数据截止2025-04-11，网页最后更新2025-05-07；清单采用后者作为保守可知日，不冒充首次公开日。Meta与Amazon数字单位主要为USD million；TSMC868.46 TWD billion是Q4而非全年。早期多值卡片拆分在旧源码快照保留。

原生PDF集 `data/native/` 新增NVIDIA FY2025 CFO Commentary、Apple FY2025 Q4财务报表、腾讯2025Q2中文业绩，连同Meta/Amazon共五份PDF、12题。来源清单含官方URL、公开日、SHA-256和下载路径。腾讯PDF由正常浏览器请求取得：普通请求曾返回JavaScript提示页，不把它当PDF；保存了实际PDF哈希。脚本遇到非PDF会明确失败。若官网要求浏览器，应正常下载清单原链接并放到指定缓存位置，再核验SHA-256。扫描OCR未实现。

FinanceBench来自作者仓库固定提交 `cc39aeb4afdf33909ee1412188bf89035950c2eb`。公开150题、32家公司，四份已有GPT/Claude响应文件每份150条；我们按哈希选一条开发响应，另从其余文件固定选一条验证响应，每方法共300条，两个判据产生600行。所有调用为Hy3；GPT/Claude内容只是作者公开的历史被评材料。验证共享开发问题/公司，公开基准也不能排除模型预训练污染。600条标签和输入哈希实际复核通过，两组完全相同的回答字节数量为0，见 `audit/external_source_verification.json`。

## 权利与再分发

自有代码Apache-2.0；字体随附OFL。资料卡含作者转述与出处，IEA来源按其CC BY 4.0标明改写。企业财报引用保留来源权利，原件仅在本机缓存，不随包再分发。不能因为代码许可为Apache就重新许可全部资料。

[FinanceBench作者数据页](https://huggingface.co/datasets/PatronusAI/financebench)标注CC-BY-NC-4.0。原问题、证据、参考和历史回答下载到 `data/cache/financebench/`，该目录不进入公开包。公开包含固定提交下载脚本、文件哈希、响应ID、本项目Hy3分类/理由与聚合统计；复核输入和原作者人工标签时需自行下载原数据并遵守非商业等许可条件。下载记录见 `audit/financebench_download.json`。

继承的原项目合成数据与历史实验仅供追溯；2736模板项不是2736独立研究任务。原腾讯PDF缓存同样排除。

## 复现路径

**离线复算**：README列出的测试、brief replay、verify_extended、verify_artifacts无需密钥及原件缓存。评分依据已保存的答案与语义判定，检验规则复算、协议与片段绑定，不证明模型判定正确。`verify_clean_checkout.py`在同机解释器的临时无密钥副本阻断外网后执行，不称独立第三方复现。

**原数据复核**：运行 `python scripts/download_financebench.py` 下载固定版本，再执行 `python scripts/verify_extended.py --with-source` 对600行的人工标签、候选哈希和提示输入哈希逐条核对。官方PDF用 `python scripts/download_native_reports.py`按清单下载并核验；哈希不符或非PDF会失败，不静默覆盖固定原件。

**在线新实验**：以下命令会产生Hy3费用，应先按README配置密钥、no_think、温度0和max_tokens6500。脚本检查冻结协议；已有成功结果会跳过。需要全新响应时在独立源码副本保留原结果备份后清理对应输出，不覆盖本包证据。

```bash
python scripts/run_brief_experiments.py --phase dev --run v3 --workers 2
python scripts/run_brief_experiments.py --phase evaluation --run v3 --workers 2
python scripts/run_brief_experiments.py --phase metaeval --run v3 --workers 2
python scripts/run_grounded_experiments.py --phase application --workers 2
python scripts/run_grounded_experiments.py --phase order --workers 2
python scripts/run_external_human_v3.py --execute --workers 2
python scripts/run_semantic_stress.py --execute
python scripts/run_native_pdf_v5.py --execute
python scripts/run_native_validation_v2.py --execute
```

主brief以每次记录中的实际配置为准，协议和每次trace提供实际参数。外部与金额压力实验实际使用max_tokens2400，复跑参数分别按trace中的实际配置设置。Hy3是供应商模型别名，不能冻结其内部权重；温度0仍可能不同。

外部v3基线复用v2开发判定，完整重建依赖v2；同预算实验也复用brief v3初稿。复用依赖是协议的一部分，全量重建须按依赖顺序执行。脚本名及参数见 `scripts/` 源码。

## 完整记录、失败与成本

所有最终计划已按 `results/final_status.json`列出；历史HTTP402/429与原生PDF结构失败保留在历史版本/attempt_history/resume_history。恢复只补缺失，不按分数重抽答案。失败填零均值衡量可用性，不能用来排名纯内容质量。

每个成功响应尽可能保留usage、延迟、推理配置、请求哈希、供应商请求ID哈希。早期trace未完整记录所有环境变量（如max_tokens），不可声称锁定了全部供应商生成参数；最终运行配置另见 `audit/final_runtime_settings.json`。早期brief v1及native v1部分结构失败没有完整中间响应，真实缺口不能补写。公开副本只对旧错误消息中的请求标识进行哈希化，变更前/后哈希在 `audit/public_redactions.json`；没有改结果或分数。

`scripts/analyze_extended.py`按请求哈希去重，包括重复使用的初稿与真实浏览器调用。调用与tokens汇总限于有保存记录的请求；缺少usage的失败及未保全响应不计入统计。历史结果中的标价估算记录其当时假设，不属于新的实时价格查询。UTC时间使用实际进程时钟。续跑累计wall_seconds包含实际处理时间，不含两次尝试间等待，也不等于新鲜单次延迟。
