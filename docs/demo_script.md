# ChronoFin 两分钟演示脚本与实际 GIF

已生成的 56 秒无声离线回放见 [`assets/chronofin_demo.gif`](../assets/chronofin_demo.gif)。它读取冻结的腾讯公开案例、当前确定性稳定性检查、保存的 Hy3 因果答案、形式化压力集、组件消融与可见回归夹具；不联网、不调用模型、不读取 API Key。重新生成：

```bash
python -m pip install -e '.[demo]'
python scripts/build_demo_gif.py
```

GIF 可直接作为提交附件。下面是与八帧画面对应的 1 分 55 秒带口播版本。计时段只回放已保存结果，避免把网络波动或历史答案误说成当前在线调用。

## 演示失败保护与表述边界

- 浏览器或网络异常时，直接播放 GIF 或展示上述本地 HTML/JSON；计时段不重跑 Hy3。
- `live_causal_experiment_current.json` 是**保存的历史 Hy3 答案经当前确定性合约重处理**，不是当前在线模型调用。
- 当前 5 次重复是**确定性评分实现稳定性**，不是模型语义一致性实验。
- 当前 6/6 基础案例与 3/3 未来泄漏攻击是开发时已可见的回归夹具，不宣称外部时间戳、真正 post-freeze 或 held-out。
- `PDA = 1`、`IVR = 0` 和 100% 破坏检出率只描述固定的合成形式化矩阵，不等同于真实金融问答准确率。
