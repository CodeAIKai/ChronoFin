# ChronoFin「时证」项目说明

作者：[CodeAIKai](https://github.com/CodeAIKai)。本项目为 **2026腾讯犀牛鸟开源人才培养计划个人活动作品**，选择任务1「AI应用与评判标准设计」，金融分析方向。在线生成、修订与语义评判均通过腾讯TokenHub调用Hy3，无训练或微调。

## 应用场景

面向财报阅读、行业研究摘要及公开资料问答，服务研究晨会准备和结论核查。使用者输入研究问题与信息截止日，上传文字PDF或选用登记资料，获得带引用的研究简报。界面区分事实、预测、推断和未知事项，并呈现逐项引用、计算记录、反证与十维审计。

Hy3负责跨段综合、反证审阅与语义判定；程序负责资料日期过滤、原文与候选片段绑定、类型化财务运算和结构约束。原稿、修订稿及评判依据均可追溯。

## 实证范围

主要开放式应用实验为20题、三种方案；额外验证包含15题同调用次数比较、48次顺序/重复评判、30个金额与语义压力项，以及五份官方PDF的12题回归。公开FinanceBench人工标签实验涵盖150题、32家公司，在共享问题的新响应上验证三分类判据。各实验统计单位和重复关系见报告，记录数不等于独立问题数。

样本由作者整理，开放式十维评价尚无新增专家盲标；同Hy3家族评判偏差和复杂PDF处理仍有限制。原始结果保留失败与误判，诊断分是项目方法指标。
