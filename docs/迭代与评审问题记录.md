# 实现迭代与实验验证

以下以保存的代码、协议、原回答和判定为依据；分数不是官方评分，也不是纯财务正确率。失败记录保留，版本变更后不覆盖旧输出。

| 评审问题 | 观察到的实际问题 | 实现/实验 | 结果与边界 |
|---|---|---|---|
| 原项目是否真的运行？ | 模板高分不能证明开放式能力 | 121项原测试、离线脚本、两种推理配置Hy3+腾讯原PDF、真实Streamlit交互 | 原版披露后partial/20；不同协议不能与新97分直接比较 |
| 模型是否只是在复制引文？ | 原确定性文字投影覆盖模型原稿 | brief原始初稿→工具检查→Hy3反证修订，原话与修订留存 | D/E20题×3方案60/60，保留早期结构失败 |
| 判断覆盖是否只看证据ID？ | 只引用ID可能没有表达反证 | 正文片段核验、逐claim支持、摘要与类型/范围检查 | 主变形12个有害样本全部降分；不声称全攻击覆盖 |
| 多一次调用是否解释优势？ | 两轮对单轮不公平 | 同完整资料初稿＋通用二次修订，对照第一稿消融，统一新裁判 | 15题反证91.861对通用86.523，tokens少30.6%；小样本来源组区间探索性 |
| 评委自己是否稳定？ | D01金额正确却因逆序从100降55 | Decimal数额见证，6答卷×2裁判×4顺序/重复条件 | 平均极差9.167→2.333，仍有一答卷极差6 |
| 只证明换算会不会掩盖语义错误？ | 正确金额可挂错主体、期间或预测类型 | 6金额×5状态，两个裁判共60判定 | 旧24/30、新30/30；30合成项不是现实100%准确率 |
| 外部人工是否认同？ | v1参考版本不一致；复杂判据v2未优于简洁，74%对74.7% | 用同一历史行gold_answer；按开发分歧操作化明确拒答/答非所问 | 新选150响应78%→90%，κ0.666→0.849；共享问题、15项分歧，非十维专家盲标 |
| 能否处理新增原财报？ | native v1长参考ID导致2/3失败 | 短ID与独立criteria，原文审计，检查点保存，固定一次格式修复 | v2完成12/12但数值/引文问题仍多，不能只报成功率 |
| 数值证明为何仍错？ | v2空数值登记、引句自行改写；v3严格校验后4/12失败 | v4原文行区间→程序复制；候选句ID→程序绑定 | v4仍11/12，自由公式单位错误与股票千股换算错误保留 |
| 可执行公式是否就财务正确？ | Amazon多乘10；腾讯63052百万写成63.052亿；同一ID混比较期 | v5四类类型化运算、单位尺度编译、独立数值卡提示、一次proof修复 | 12/12完成；同一v5裁判重评旧v2，12题提升21.123分，8胜3平1负；AP02无效同ID增长仍存在 |
| 换评委会不会制造改进？ | 各版分数不能直接作因果增益 | final v5同裁判重评v2旧稿＋9个破坏/9个等价重复 | 9/9破坏降分；9个等价/重复中1个变化>5。不是完全稳定 |
| UI有接口是否就算能用？ | 最终PDF上传通过，但自定义问题第一次裁判把候选limitations当参考 | 实时统一候选片段裁判，明确空参考并最多一次格式修复 | 实际重新走浏览器，不mock模型；第一次失败见audit/live_history/v5_first |
| 没有金标能否给100分？ | 临时自定义问题没有完整性参考 | 无参考三维为null、总分null，其他证据支持实测 | 真实上传及自定义问题均检查未知维度，不凭缺失给高分 |
| 结果不理想是否隐藏？ | 原生TC03低分、AP02无效计算、早期402/429/格式失败 | 保留全部历史；前端对部分支持、无效同ID跨期计算显示复核提示 | 已知缺口直接进入分析报告，不按高分筛选或冒充专家意见 |
| 离线证据链是否依赖本机缓存？ | 已安装依赖、秘密变量和原件缓存可能遮蔽缺失文件 | 临时副本排除密钥和原PDF缓存，阻断非环回网络后运行测试与复算 | 执行记录、源码指纹和逐步骤日志见audit/clean_checkout_verification.json；使用同机解释器 |

主资料、样本与协议早已冻结，后续新增来源只用于单列原生PDF回归。没有跨模型训练、微调或其他模型API。所有改进经过实际运行后再写结果，不用方案代替执行。完整验证状态以最终机器文件为准。
