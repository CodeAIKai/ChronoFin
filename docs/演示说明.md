# 演示说明

[89秒完整配音视频](../demo/时证_参赛演示_完整版_配音.mp4)展示ChronoFin「时证」的完整流程：阅读研究结论、核查引用、查看十维审计、检查披露时点，再比较应用方法和验证评判标准。[章节与播放说明](../demo/完整版使用说明.md)提供暂停、定位及字幕方法。

画面来自真实工作台，回放已保存的Hy3响应。腾讯案例使用菜单中的“TC01 · 研究简报演示”，研究结论、引用及审计绑定同一份新答卷，记录、修订输入与独立判定见[results/demo/](../results/demo/)。这项演示修订不计入原12题回归或其他实验对照统计。

视频时长89秒，1440×1000、25帧/秒，含中文合成配音。剪辑为阅读安排停留时间，不用于测量接口延迟。原76秒视频与早期GIF仍保留。

实时PDF上传、自定义问答的实际调用与交互记录见 `audit/ui_live_verification.json`；研究结论的适用范围及实验分母见[实验分析报告](最终实验分析报告.md)。
