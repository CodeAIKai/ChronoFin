# 演示说明

[76秒中文配音视频](../demo/时证_参赛演示_配音版.mp4)展示ChronoFin「时证」金融研究工作台，包含项目介绍、TC01财报引用、十维审计、TC02披露时点检查、应用对照及公开人工标签验证。[播放说明与章节时间](../demo/参赛版使用说明.md)提供暂停、定位及字幕使用方法。

画面来自真实工作台，回放已保存的Hy3实验结果。剪辑为阅读安排停留时间，不用于测量接口延迟。视频时长76秒，1440×1000、25帧/秒，含中文合成配音。

实时PDF上传与自定义问答的实际模型调用、浏览器交互及错误记录保存在 `audit/ui_live_verification.json` 和相关模型trace中。视频中的诊断分属于项目评价方法，详细样本分母、比较条件与研究限制见[实验分析报告](最终实验分析报告.md)。

`assets/chronofin_demo.gif`与`assets/chronofin_demo_actual.gif`保存早期阶段演示，用于历史产物复核；当前演示入口为上述76秒视频。
