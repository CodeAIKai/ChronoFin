# 演示视频使用说明

[播放或下载《时政_demo.mp4》](时政_demo.mp4)。本视频展示 ChronoFin「时证」的完整操作流程，时长 **1分29秒**，包含中文合成配音和画面章节文字。

在 GitHub 打开视频文件后，若页面未直接播放，点击下载按钮保存到本地，再用浏览器或视频播放器打开。点击暂停按钮可停留阅读，拖动进度条可定位；下表列出各段起始时间。

| 00:22 | 核查财报引用：原文、页码和来源 |

| 00:47 | 检查披露时点：TC02 |

| 01:19 | 项目与公开仓库 |

视频格式为 MP4，1440×1000、25帧/秒，H.264 视频与 AAC 音频。

画面来自实际工作台，回放已保存的真实 Hy3 结果；经剪辑安排阅读时间，不代表实时生成速度。研究结论、引用和审计使用同一份[腾讯案例记录](../results/demo/TC01_demo.json)。该案例不计入原12题回归或对照均值，实验对照表沿用冻结结果。诊断分是项目方法指标，不是官方评分。方法及结果见[完整实验报告](../docs/最终实验分析报告.md)。
